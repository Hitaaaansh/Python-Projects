# Python Projects

A collection of Python projects built while working through Angela Yu's
100 Days of Code bootcamp (Udemy). Each folder is a standalone project.

## Projects

| Project | What it does | Tech |
|---|---|---|
| Password Manager | GUI app to generate and store passwords locally | Tkinter, JSON |
| Flash Card App | Vocabulary flash cards that track words still to learn | Tkinter, Pandas, CSV |
| Guess the State | Quiz game that checks answers against a dataset of states | Turtle, Pandas, CSV |
| Pomodoro Timer | Work/break timer with a countdown display | Tkinter |
| Mile to Km Converter | Simple unit conversion GUI | Tkinter |
| NATO Alphabet | Converts a word to NATO phonetic code | Pandas, comprehensions |
| Mail Merge | Fills letter templates from a list of names | File handling |

## Run a project
1. Clone the repo
2. Install dependencies: `pip install pandas`
3. Run `python main.py` inside the project folder

## Note
Sensitive data has been removed. Sample data is used where needed.
